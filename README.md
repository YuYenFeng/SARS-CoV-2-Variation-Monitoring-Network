# SARS-CoV-2-Variation-Monitoring-Network
This platform analyzes GISAID whole-genome sequences to track SARS-CoV-2 variants by country or worldwide. Users can follow the spread of variants, mutations across viral genes such as the S gene, and time-lapse trends of specific mutation sites. Methods: Yang et al., PNAS 2020; PNAS Nexus 2022.
